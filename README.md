# Tent & Table

A phone-friendly web app for running a ministry's events: volunteers, guests, tasks, prayer, money and follow-up in one place.

- **Live app:** https://solomonrowland.github.io/tent-and-table/ (opens `events/`)
- **Try the demo:** https://solomonrowland.github.io/tent-and-table/events/?demo

On a phone, open the live app and add it to your home screen (iPhone: Safari > Share > Add to Home Screen; Android: Chrome > ⋮ > Install app).

## What's here

- `events/` is the app. Its own README explains every feature and file.
- `home/supabase.js` is the Supabase client the app loads.
- `events/supabase/schema.sql` sets up the database; run it in Supabase's SQL Editor (safe to run again).
- `events/supabase/NOTIFY.md` turns on automatic texts and emails.

The site is served by GitHub Pages from the `main` branch.
